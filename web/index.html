Threat: phishing

Is this link a scam?

"Your KYC expires today, click here." Paste a link from an SMS, WhatsApp or email. Don't open it first.

Example of a real scam pattern, already checked. Paste your own link to replace it.

How it works: scam links are built to look right at a glance. This checks for the tricks they use: bank and app names in front of someone else's domain, fake government sites (real ones end in .gov.in or .nic.in), pages made with free website builders, look-alike letters, hidden number addresses, and cheap throwaway domain endings.

No red flags doesn't prove a link is safe. For banks, open the official app or type the address yourself.

Threat: guessed or leaked passwords

How strong is this password?

Checked on this device as you type. Try one you use, or a new one you're thinking of.

Start typing to see a rating.

Privacy: the password is turned into a SHA-1 hash (a fingerprint that can't be reversed). Only the first 5 characters, highlighted below, go to the Have I Been Pwned service. It replies with hundreds of leaked hashes that start the same way, and the match is found here.

Threat: one weak password reused everywhere

Make a password you can remember

Six random words beat "Rahul@1990". Pick one you like; each is freshly made by your device's secure random generator.

Why words? The computer picks each word at random from 270, so every word multiplies the guesses an attacker needs by 270. People choosing "random" words themselves is not random at all.

Best of all: use a password manager (Bitwarden is free) and only remember one of these.

Threat: a lost phone, laptop or pen drive

Lock a family document

Aadhaar, PAN, passport scans, insurance and medical papers. The locked copy is safe to keep in cloud storage or on a pen drive. The file never leaves this device.

If you forget the passphrase, nobody can open the file. That is what makes it secure. Write it down and keep it somewhere physically safe.

How it works: scrypt turns your passphrase into a key, slowly on purpose, so an attacker can only try a handful of guesses per second. The file is then encrypted with AES and sealed with HMAC, so any change to it is detected. Files work with the Family Shield desktop program too.
